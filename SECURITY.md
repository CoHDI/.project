# Security Policy

## Reporting Security Issues

The CoHDI maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/CoHDI/CoHDI/security/advisories/new) form.

For more details, see the [CoHDI security policy](https://github.com/CoHDI/CoHDI/blob/main/SECURITY.md).
